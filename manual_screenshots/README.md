# Panduan Tangkapan Layar (Screenshots) Buku Manual Smart Kids

Folder ini (`manual_screenshots/`) disiapkan khusus untuk menampung seluruh file gambar tangkapan layar.

### Cara Penggunaan Praktis:
1. Ambil tangkapan layar (screenshot) sesuai daftar 47 nomor di bawah menggunakan shortcut `Win + Shift + S`.
2. Simpan file gambar ke dalam folder `manual_screenshots/` dengan format penamaan angka: `01.png`, `02.png`, dst. (atau `01_beranda.png`). Format `.png` atau `.jpg` didukung.
3. Jalankan script penempel gambar otomatis di terminal:
   ```bash
   python scratch/insert_screenshots.py
   ```
4. Dokumen Word baru `Buku_Manual_Panduan_Sistem_Smart_Kids_Lengkap_Gambar.docx` akan langsung terbit dengan seluruh gambar Anda tertempel rapi di kotaknya!
